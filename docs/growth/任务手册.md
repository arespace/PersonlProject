## 一、项目线：魂类战斗核心

设计正本：`docs/superpowers/specs/2026-10-09-soulslike-combat-core-design.md`
目标循环：**锁定 → 观察前摇 → 选择（攻击 / 翻滚 / 格挡）→ 消耗耐力 → 无敌帧或硬直 → 反击窗口**

### 1.1 状态与标签底座

- [ ] 在 `PPTags.h` 补齐状态标签：`State.InAction.{Attacking,Rolling,Blocking,HitReact,Riposte}`、`State.Action.Dead`、`State.Invulnerable`、`State.InAction.Blocking.ParryWindow`、`State.Stamina.RegenBlocked`
      **验收**：编辑器 GameplayTags 列表里能看到全部条目，且是 C++ 声明的 native tag（不依赖 `DefaultGameplayTags.ini`）
- [ ] 给现有 GA 补 `ActivationOwnedTags` / `ActivationBlockedTags` / `CancelAbilitiesWithTag`
      **验收**：翻滚期间按攻击键无反应；受击硬直能打断攻击

### 1.2 耐力

- [ ] `PP_AttributeSet` 增加 `Stamina` / `MaxStamina`
- [ ] 耐力消耗与回复 GE（回复在 `State.Stamina.RegenBlocked` 下停摆）
      **验收**：连续攻击把耐力打空后攻击键失效；停手后耐力条回满

### 1.3 翻滚与无敌帧

- [ ] 翻滚 GA（`State.InAction.Rolling` + `State.Invulnerable`）
- [ ] `UInvulnerabilityWindow`（`UAnimNotifyState`）：`NotifyBegin` 加 `State.Invulnerable`，`NotifyEnd` 移除
      **验收**：翻滚中穿过程序化伤害不掉血；无敌帧外同一伤害照掉
- [ ] 资产：翻滚 / 闪避动画（**当前缺口**，spec 记载缺失）

### 1.4 输入缓冲与行动预检

- [ ] `UActionStateComponent`：输入缓冲 + 行动预检 + 状态查询
- [ ] 通过 `UPROPERTY(BlueprintAssignable) FOnValidateAction OnValidateAction` 注入项目侧判定（如「耐力是否足够」）
      **验收**：翻滚结束前 0.2s 内按攻击，翻滚结束后自动接上攻击

### 1.5 锁定

- [ ] `ULockOnComponent`：目标选择（按 `Character.Enemy` 标签过滤）+ 相机接管 + 目标死亡/丢失时解除
      **验收**：锁定后角色始终面向目标；目标死亡自动解锁

### 1.6 韧性硬直与格挡弹反

- [ ] 累计伤害超过韧性阈值 → 触发 `HitReact` GA（带 `CancelAbilitiesWithTag = State.InAction.HitReact`）
- [ ] 格挡 GA：扣减伤害 + `ParryWindow` 内命中转为弹反
      **验收**：弹反窗口内被击中 → 敌人进入 `Riposte` 可处决状态
- [ ] 资产：格挡被击动画（**当前缺口**）

### 1.7 位移对齐

- [ ] 接入 Motion Warping，翻滚/攻击位移对齐动画（spec 里标为**强制项**）
      **验收**：不同起始距离下翻滚落点与动画一致

### 1.8 技术债收敛

- [ ] 三套伤害链路并存 → 收敛到 `PP_DamageExecutionCalculation` 单一入口
      （现存：`PP_BlueprintLibrary.cpp:83-133`、`:135-174`、`PP_Primary.cpp:132-136`）
      **验收**：全项目伤害都走 ExecCalc，旧入口删除或标 `Deprecated`
- [ ] `Config/DefaultGame.ini` 补 `ProjectName` / `ProjectVersion`（`[/Script/EngineSettings.GeneralProjectSettings]` 现在只有 `ProjectID`、`CopyrightNotice`）

### 1.9 抽成插件 `ActionCombatCore`

- [ ] 建 `Plugins/ActionCombatCore/`，迁入 `UActionStateComponent` / `UInvulnerabilityWindow` / `ULockOnComponent` / `ActionCombatTags.h`
      **硬约束（用编译器和 review 守住）**：
      1. 插件内不得出现任何 `PP_` 前缀符号
      2. 插件不得 include 项目头文件；依赖单向：项目 → 插件
      3. 插件不引用 `PPTags.h`
      **验收**：把 `PersonalProject` 的 Source 整个重命名，插件仍能独立编译

### 1.10 已知遗留（**不列为任务，除非你决定要修**）

- `PP_CrashGameMode` 的 `CharacterAbilityMap` 从未生效 —— 换大厅角色不会换技能。根因是无缝切图不调 `PostLogin`，而角色自己走 `PP_PlayerCharacter.cpp:111` 的 `GiveStartupAbilities()`，把这条路盖住了。修法是 override `GenericPlayerInitialization`（无缝/非无缝的唯一交汇点）。
