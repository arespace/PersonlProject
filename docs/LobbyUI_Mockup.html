V1.1 相对 V1 改了什么（点击展开）
  1. 修布局抖动：房主专属按钮（StartButton / RoomSettingsButton）由 Collapsed 改为「禁用 + 占位 + tooltip」，切换房主不再位移。
  2. 底栏减负：由 8 个元素压到「已准备 + 倒计时 | 准备(主) / 开始 / 房间设置 ‖ 离开(危险)」，并用分隔线隔离危险操作。
  3. 危险操作隔离：离开房间独立到分隔线右侧，避免与「开始游戏」相邻误点。
  4. 补齐三态：搜索中 loading、倒计时中央覆盖层（大字 + 进度环）、房主迁移顶部提示条。
  5. 去重复信息：房间名/地图/模式/人数统一放顶栏，左栏只保留队伍列表，「房主：陈天宝」不再三处重复。
  6. 中部填实：删掉与底部 minis 重复的 ‹ › 箭头；加入光柱 + 地台 + 暗角三段式背景（RT 带 alpha 不会飘）； 用真实字段 Description 填充空白，并把「更换角色」入口移到这里。
  7. 删掉假数据：大厅顶栏的 24ms 改为 Session 状态（Ping 不在 FLobbyPlayerInfo 里，且本地 Ping 不代表他人）。
  8. 隐藏内部名：不再显示 Greystone / mesh 路径等资产名，只暴露 DisplayName / CharacterIcon / Description。
  9. 玩家列表可滚动：补齐到 MaxPlayers 并套 ScrollBox，避免 MaxPlayers=8 时溢出。
  10. 视觉层次：面板加顶部 1px 高光渐变；字号收敛到 11/13/16/20 四档。
  11. 聊天增强：加时间戳 + 显式发送按钮；新消息需在 ScrollBox 处于底部时才自动滚动。
  12. 可交互预览：顶部控制条可切换 房主/非房主、等待准备/倒计时/迁移、显示/隐藏字段标注。
