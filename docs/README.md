# 文档索引

本索引是 `docs/` 的唯一入口。每份文档开头都带状态块，状态含义：**现行**（可作开工依据）、**细节参考**（提供证据与文件级细节，不决定排期）、**背景资料**（仅供参考，不作为开工依据）、**已被取代**（仅存档）、**临时记录**（一次性结论，可能已过期）。

> **状态块与本索引不一致时，以本索引为准。**

## 命名与维护规则

- **目录不新增第二套分类**：新文档只能进 `架构 / 计划 / 规范 / 方案 / 参考 / 复盘`；`superpowers/specs`、`归档`、`growth` 为既有例外，不扩用。
- **文件名**：中文标题式命名（`架构总览.md`、`GAS技能系统.md`、`Git工作流.md`、`Content新建规范.md`）。仅以下保留英文：`README.md`、`FEATURE_PLAN.md`、spec 的 `YYYY-MM-DD-<topic>-design.md`、HTML 原型文件。
  - `计划/FEATURE_PLAN.md` 是例外：`复盘/功能收口清单.md` 以纯文本引用了该路径，而复盘只增不改，故永久保留原名。
- **同一主题只留一份**：内容重复的文档合并进唯一事实源，其余移入 `归档/`，不并行维护。
- **链接**：一律写相对路径，禁止绝对路径；移动文档后必须同步修正引用（含 `.trae/skills/pp-dev` 中指向 `docs/` 的路径）。
- **新增或移动任何文档，必须同步更新本索引**。
